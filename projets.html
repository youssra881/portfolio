Site web TechSolutions

Projet de BTS : créer le site d’une entreprise fictive, TechSolutions, d’abord comme site vitrine, puis comme site dynamique avec une base de données et un espace client.

Les étapes du projet

  • Site vitrine en HTML et CSS : plusieurs pages reliées par un menu horizontal, avec la charte graphique du client.
  • Installation d’un serveur local (Apache, PHP, MySQL) pour faire fonctionner le site sur mon ordinateur.
  • PHP : variables, calculs, fichiers communs, conditions et boucles.
  • Base de données MySQL : lire, ajouter, modifier et supprimer des données en SQL.
  • Affichage dans les pages des données lues dans la base.
  • Connexion par identifiant et mot de passe, puis espace administrateur qui gère les comptes.

Ce que ce projet me permet d’apprendre

  • Faire évoluer un site vitrine vers un site dynamique.
  • Relier des pages PHP à une base de données MySQL.
  • Utiliser des requêtes SQL pour lire et gérer des données.
  • Organiser un projet qui comporte plusieurs pages et fonctionnalités.
